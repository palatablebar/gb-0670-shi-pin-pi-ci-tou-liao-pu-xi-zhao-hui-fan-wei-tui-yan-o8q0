# 演示路线

1. 进入台账采信，选择生产异常台账，起点R-0001，登记并运行。
2. 在计量契约核对全角80与50000g的归一结果。
3. 在投料谱系检查重复、撤回和冲突事件。
4. 在质量隔离查看质量失败的原始行号和原因码。
5. 改用已核验台账，再在召回推演输入R-0099；应涉及37批，含24个末端成品批。
6. 在物料对账复核48笔有效投料、2280kg累计投入和96kg损耗。
7. 在批次归档按原参数重跑，应复用相同运行号；质量隔离提交复核后，旧版本API提交返回409。

生产异常样例包含全角数量、单位不支持、空值、半行、重复表头、重复事件、冲突版本、撤回、谱系环和失联。干净和脏样例均走同一条解析与校验路径。
